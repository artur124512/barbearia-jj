# Barbearia J&J - Landing Page & Agendamento Online

Single Page Application (SPA) moderna, rápida e de alta conversão desenvolvida para a **Barbearia J&J**, destacando o atendimento exclusivo do barbeiro **Joares Meireles** e a integração direta com o sistema de agendamento online.

---

## ✨ Tecnologias
- **Framework:** React 18 + Vite + TypeScript
- **Estilização:** Tailwind CSS (Dark Luxury #0D0D10 e Dourado Vintage #D4AF37)
- **Tipografia:** Playfair / Cinzel & Plus Jakarta Sans
- **Ícones:** Lucide React
- **Animações:** Framer Motion
